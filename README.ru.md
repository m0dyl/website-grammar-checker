# Website Grammar Checker

Проверка орфографии и грамматики на внутренних страницах сайта. Скрипт загружает HTML с паузами, извлекает текст и проверяет его локальным LanguageTool. Результат — JSON с адресами страниц, контекстом и предложениями исправления.

[English README](README.md) · [Авторизация](AUTHENTICATION.md) · [Пример отчета](examples/report.example.json)

## Быстрый запуск

Нужны Python **3.10+** и Java **17+**. Python 3.15 не является обязательным.

В PowerShell из папки проекта:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
java -version
```

Если Java нет:

```powershell
winget install --id EclipseAdoptium.Temurin.21.JDK --exact
```

После установки перезапустите терминал и редактор. Затем в начале `main.py` задайте свой сайт:

```python
SITE_URL = "https://example.com/"
MAIN_LANGUAGE = "pl"  # Польский: pl; русский: ru; украинский: uk.
REQUEST_DELAY = 2.0
MAX_PAGES = 500
```

Запуск:

```powershell
.\venv\Scripts\python.exe main.py
```

При первом запуске скачивается LanguageTool. Результат сохраняется в `grammar_report.json` в текущей рабочей папке. Промежуточный отчет обновляется после каждой страницы.

## Фильтры

- `URL_IGNORE = ["/blog"]` исключает `/blog` и `/blog/...`, но не `/other/blog` или `/blog-new`. Можно вставлять полные URL того же хоста.
- `RULE_ID_IGNORE` скрывает все замечания с указанными ID. По умолчанию список пуст; `AL_UJAZDOWSKIE` оставлен как закомментированный пример.
- `ENGLISH_IGNORE = True` допускает английские слова при основной орфографической проверке. Грамматика смешанных предложений не объединяется.
- `ALL_CAPITAL_LETTERS_IGNORE = True` пропускает замечания к отдельным словам ЗАГЛАВНЫМИ.
- `HYPHEN_DASH_IGNORE = True` скрывает узкие замечания о замене дефиса на тире.
- `IGNORE_LOWERCASE_FRAGMENT_START = True` допускает маленькую букву в начале извлеченного фрагмента.
- `IGNORE_ADDRESS_NUMBER_WARNING = True` подавляет ложное замечание LICZEBNIKI к буквенной части номера в распознанном польском адресе.

`False` отключает соответствующее исключение. Полный список настроек находится в [English README](README.md#settings).

## Закрытые страницы

Необязательные `REQUEST_HEADERS`, `REQUEST_COOKIES`, `HTTP_BASIC_AUTH` передаются через requests. По умолчанию они равны `None`. Примеры и ограничения — в [AUTHENTICATION.md](AUTHENTICATION.md). Реальные секреты храните в переменных окружения через `env:ИМЯ`, а не в файлах для GitHub.

## Что пока не поддерживается

Скрипт не выполняет JavaScript, не решает CAPTCHA и не гарантирует обнаружение всех страниц сайта. Он не читает sitemap и robots.txt; правила сайта и подходящую нагрузку нужно учитывать самостоятельно. `www` и домен без `www` считаются разными хостами. Возможны ложные замечания, особенно в названиях брендов и смешанном тексте. Ошибки общего футера пока повторяются для каждой страницы.

Статус `checked` означает выполненную проверку извлеченного текста, а не гарантию отсутствия ошибок. При `blocked` или `error` содержимое страницы не считается полностью проверенным.

## Тесты

```powershell
.\venv\Scripts\python.exe -B -m unittest discover -v
```

Тесты локальные: без сети, Java и настоящих токенов. Реальные отчеты игнорируются Git, поскольку могут содержать текст закрытых страниц. Пример в `examples/` вымышленный.
